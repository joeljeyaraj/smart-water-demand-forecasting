# Smart Water Demand Forecasting Using Data Science

## Project Overview
This project predicts water demand using machine learning techniques based on factors such as population, temperature, and reservoir levels.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Models
- Linear Regression
- Polynomial Regression
- Decision Tree Regression

## Dataset
The dataset contains:
- Chennai water consumption data
- Reservoir water level data

## Goal
To help improve smart city water management and forecasting.
